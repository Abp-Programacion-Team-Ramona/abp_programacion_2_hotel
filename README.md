# Ramona Hotel — Sistema de Gestión Hotelera

## Introducción

Ramona Hotel es un sistema de gestión hotelera desarrollado como trabajo de Evidencia de aprendizaje por el equipo Ramona. El propósito del sistema es centralizar y simplificar la administración de un hotel, resolviendo la necesidad de contar con una herramienta que atienda tanto a los clientes como al personal administrativo desde una misma plataforma.

El problema que busca resolver es la falta de visibilidad y control sobre el estado del hotel en tiempo real: ocupación, reservas, check-ins, check-outs y rendimiento de servicios, todo accesible desde un panel unificado.

## Funcionalidades

**Vista del cliente**
- Presentación del hotel y sus servicios
- Navegación por las secciones del establecimiento

**Vista del administrador**
- Panel con métricas de ocupación actual
- Control de habitaciones ocupadas y disponibles
- Seguimiento de check-ins y check-outs del día
- Gráfico de ocupación semanal
- Indicadores de rendimiento por servicio (restaurante, spa, habitaciones, eventos, estacionamiento)
- Listado de próximas reservas con detalle de habitación y huésped

## Instalación y ejecución

1. Clonar o descargar el repositorio:
   git clone https://github.com/Abp-Programacion-Team-Ramona/abp_programacion_2_hotel
2. Ubicarse en la carpeta "frontend" del proyecto: cd frontend en el cli
3. Ejecutar ng serve --open
